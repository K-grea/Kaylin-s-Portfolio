# Kaylin's Portfolio

## Visual Design

### Gestalt Principal 1: Proximity
I used proximity by grouping my Home, About, and Work navigation links together. Since the links are close to each other, users can easily tell that they are all part of the website navigation.


### Gestalt Principal 2: Similarity
I used similarty by keeping the ame colors, fonts, and heading styles throughout my pages. The consistent pink and white color palette helps make all three pages feel like they belong to the same portfolio website.

## Color Palette
My portfolio uses a consistent color palette of pink, white, dark gray, and light pink. I kept these colors consistent across the Home, About, and Work pages.
